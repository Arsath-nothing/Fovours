# Fovorse Intelligence

A responsive, single-page website for Fovorse Intelligence, featuring its AI automation services, programs, careers, projects, and contact information.

## Run locally

This is a static website and does not require a build step or package installation. Open the HTML file directly in a browser:

`Fovorse Intelligence _ AI Automation, LLM & AI Agent Development (1).html`

The site also works when served by any static file server. Some fonts are loaded from Google Fonts, so an internet connection is needed for those fonts.

## Make changes

The page markup, styles, scripts, content, and image assets are contained in the HTML file. Edit that file to update the site. Navigation between sections uses URL hashes.
